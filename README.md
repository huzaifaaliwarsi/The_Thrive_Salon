# The Thrive - Salon Management System

A comprehensive multi-branch salon management and point-of-sale (POS) software built with Flutter (Frontend) and Node.js / Express / TypeScript / PostgreSQL (Backend).

## Features

- **Point of Sale (POS):** Fast checkout, service and package billing, cash/card payment processing, receipt printing.
- **Appointments & Booking:** Real-time scheduling, client booking calendar, status tracking.
- **Biometric Attendance (ZKTeco):** Cloud push integration for biometric attendance machines.
- **Staff & Payroll:** Attendance tracking, leave management, commission and salary calculations.
- **Inventory & Purchases:** Product tracking, vendor ledger, stock movement transactions.
- **Reports & Analytics:** Sales reports, top services, staff performance, expense analysis.
- **Multi-Role Access:** Super Admin, Salon Owner, and Staff permissions.

## Architecture

- **Frontend:** Flutter Web / Mobile (Riverpod, Dio, Google Fonts, Lucide Icons)
- **Backend:** Node.js, Express, TypeScript, Drizzle ORM
- **Database:** PostgreSQL
